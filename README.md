### Hi there 👋

I'm **Matheus Perez** — Senior iOS Developer at [Mercado Bitcoin](https://www.mercadobitcoin.com.br), indie maker, and Jiu-Jitsu practitioner based in Belo Horizonte, Brazil.

I build production iOS apps for millions of users by day, and ship indie products and developer tooling by night. Most of my work lives in private repos — what you see here is the visible tip of the iceberg.

---

## What I focus on

- **Senior iOS engineering** — Swift, SwiftUI, UIKit, Combine, async/await, modular architecture, performance and accessibility at scale.
- **CI/CD for iOS** — Fastlane, Bitrise, GitHub Actions, automated TestFlight pipelines, code signing with match, snapshot tests in CI.
- **AI-augmented development** — I use Claude Code and the Anthropic API daily as part of my workflow: custom agents, skills, hooks, MCP servers, and automation tooling that ship real value, not demos.
- **Indie product building** — designing, shipping, and iterating on apps end-to-end (product → code → release → metrics).

---

## Currently working on

- 🛒 **Stoqio** — an indie iOS app for Brazilian households that turns NFe receipts into automatic home inventory. Solo project: SwiftUI, SwiftData, CoreData, on-device parsing, App Store releases.
- 🤖 **HangarAI** — a macOS menu bar app that orchestrates Claude Code routines, skills, and quick capture into my Obsidian vault. Personal productivity infra.
- 🧰 **Developer tooling & Claude Code plugins** — custom skills, sub-agents, hooks and MCP integrations that streamline iOS work (code review, refactor planning, test writing, release checklists).
- 💼 **Mercado Bitcoin iOS app** — contributing to one of LATAM's largest crypto platforms.

---

## Why most of my repos are private

A large share of my code is shipped under NDA (employer codebases) or kept private while indie products are still in active iteration. Happy to discuss architecture, decisions, and trade-offs in interviews or 1:1 — just reach out.
